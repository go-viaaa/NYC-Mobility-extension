### NYC-Mobility-Extension — Project Description

This project extends the existing NYC Mobility data engineering pipeline by enhancing its **data quality, reliability, automation, and maintainability**.

Building on the integration of **taxi trips, weather conditions, and taxi zone metadata**, the extension introduces automated **code testing, data-quality validation, and CI/CD checks** while strengthening repository governance, configuration, deployment, and documentation practices.

The goal is to make the mobility analytics pipeline **more reliable, repeatable, and collaboration-ready without unnecessarily redesigning the existing architecture**.
